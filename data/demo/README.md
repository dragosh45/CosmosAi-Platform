# Experimental Demo Checkpoint

`gz2_pilot_80.pt` is the 3,407-byte TinyGalaxyCNN checkpoint generated by this
project from the 80-image Galaxy Zoo 2 pilot. It contains 132 learned scalar
parameters, the four-label mapping and saved preprocessing metadata. It is
included so the local demo does not require the external dataset drive.

SHA-256: `6e1ee07039fcad43ebb85b0c61c2f46e714a3b72d65a632e682bc67105a1865b`

Training: 56 images, 2 epochs, seed 7, batch size 8, SGD learning rate 0.1.
Validation: 3/12 correct (25%). Test: 3/12 correct (25%). Every evaluated image
was predicted elliptical. This is an experimental pipeline baseline, not a
reliable morphology classifier. Lenticular is a derived GZ2 label proxy.

The measured model card is `../samples/gz2_pilot_model_card.json`. The service
shows its metrics only when its checksum matches the loaded checkpoint.
Four example JPEGs and their provenance notes are under `../samples/`.
The full dataset, source metadata and training reports remain outside Git.

The separate 30-epoch, 64x64 validation experiment did not improve train or
validation accuracy beyond 25%. Its test split was not evaluated, and that
candidate has not replaced this checkpoint.
