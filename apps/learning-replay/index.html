02 / CLASSIFIER

Features become class scores

Pooling produces four internal signals, a[0] through a[3], one from each filter. The final 4 x 4 matrix multiplies those signals; its outputs are logits before softmax.Matrix multiplicationLogits, softmax and loss

Feature connections

green = features, violet = classes
